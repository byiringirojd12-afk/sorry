# A Message From My Heart ❤️

A React + Vite website that recreates the supplied short video as a **live, interactive webpage**. It does not embed or play the original MP4.

## What is recreated in the browser
- Hot-pink heart-pattern banner
- Floating outline hearts in the background
- Animated particle heart rendered with HTML Canvas
- Cycling gold, purple, emerald, and gold heart scenes
- Romantic glowing text transitions
- Dark code-editor-style panel with apology-themed code
- Personal apology letter and promises
- Responsive layout and reduced-motion support

## Run locally

1. Install Node.js 18 or newer.
2. Open this folder in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Edit the scene messages in `src/App.tsx` in the `scenes` array.
- Edit the apology letter in the letter section of `src/App.tsx`.
- Adjust colors, spacing, and typography in `src/styles.css`.

## Deploy to Vercel

Import the project repository into Vercel. Use:
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

No video asset is required. The particle heart and transitions are generated by the website itself.
